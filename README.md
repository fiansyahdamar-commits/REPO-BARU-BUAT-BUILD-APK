# Zall RW Admin

Aplikasi Android admin terpisah. Client Zall RW yang sudah ada tidak diubah.

Backend: https://zallrw-vip-backend.vercel.app

Admin API yang sudah terdeteksi menggunakan header x-admin-key dan menyediakan endpoint statistik, daftar/buat kode, enable/disable kode, serta riwayat aktivasi. Endpoint login dan refresh-token khusus belum terdeteksi. Mode MULTI/SINGLE dan password redeem memerlukan dukungan backend yang belum terbukti tersedia; UI tidak boleh dianggap menjamin aturan tersebut sebelum backend diverifikasi.
